# Rasoi Rush — Food Website
Student demo website for the Digital Marketing & Social Media (ADMC301) SEO assignment.

## Files
- `index.html` — main website
- `assets/style.css` — responsive design and animation
- `assets/script.js` — menu filters, cart drawer and demo reservation form
- `assets/favicon.svg` — favicon

## Publish on GitHub Pages
1. Create a GitHub repository named `rasoi-rush`.
2. Upload all files/folders from this project.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)`.
4. After deployment, replace `YOUR-USERNAME` in `index.html` canonical/OG/JSON-LD URLs with your GitHub username.
5. Add `robots.txt` and `sitemap.xml` after the final Pages URL is known.
